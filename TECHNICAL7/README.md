# Technical 7: Data Mining

CS054 Intelligent Systems activity covering an ID3 decision tree for planet habitability and one-dimensional K-means clustering.

The supplied worksheet is named **Laboratory Activity 3**, but this project is **Technical 7**. The programs run locally without CODIO. The worksheet PDF is edited separately.

## Requirements

- Python 3.6 or later.
- A terminal, such as PowerShell.
- A browser or image viewer to open the decision tree graphic.

Both programs use only Python's standard library. No additional packages or dataset downloads are required.

## Run the programs

Open a terminal in the project folder and run:

```powershell
python decision_tree.py
python k_means.py
```

If Windows uses the Python launcher, replace `python` with `py`.

The ID3 program prints entropy, information gains, the learned tree, and the two requested predictions. It also creates or replaces `decision_tree.svg` beside the script.

The K-means program prints the distances, cluster assignments, and updated means for iterations 1 through 3. Both programs use the datasets defined in their source files and require no interactive input.

To save the console output in PowerShell:

```powershell
python decision_tree.py | Set-Content -Encoding utf8 decision_tree_output.txt
python k_means.py | Set-Content -Encoding utf8 k_means_output.txt
```

These commands replace the existing output text files. The supplied PNG is a preview; running the ID3 script regenerates only the SVG.

## ID3 decision tree

The dataset contains eight frequency rows representing **800 planets**. Each row specifies `Size`, `Orbit`, `Habitable`, and `Count`. Calculations weight each row by its count.

ID3 selects the attribute with the greatest information gain at each split. At the root:

| Measurement | Value |
| --- | ---: |
| Dataset entropy | 0.996950 bits |
| Information gain for Size | 0.012820 bits |
| Information gain for Orbit | 0.006790 bits |

**Size** becomes the root, and each Size branch splits on **Orbit**. No pruning is applied. When no attributes remain, each leaf predicts its majority class.

| Size | Orbit | Habitable count | Not-habitable count | Prediction |
| --- | --- | ---: | ---: | --- |
| Big | Near | 20 | 130 | No |
| Big | Far | 170 | 30 | Yes |
| Small | Near | 139 | 11 | Yes |
| Small | Far | 45 | 255 | No |

Both requested cases, **Big/Far** and **Small/Near**, are predicted **habitable**. These are majority-class predictions from the worksheet dataset.

## K-means clustering

The dataset is `{2, 4, 10, 12, 3, 20, 30, 11, 25}`, with `K = 2` and initial means `M1 = 4`, `M2 = 11`.

Each iteration assigns all points using absolute distance to the current means, then recalculates the means. Exact fractions are used internally; displayed distances and means are rounded to six decimal places. A distance tie goes to C1, although no tie occurs in this example.

Iteration numbering follows the worksheet's first distance table:

| Iteration | Starting means | C1 after assignment | C2 after assignment | Updated means |
| --- | --- | --- | --- | --- |
| 1 | 4, 11 | {2, 4, 3} | {10, 12, 20, 30, 11, 25} | 3, 18 |
| 2 | 3, 18 | {2, 4, 10, 3} | {12, 20, 30, 11, 25} | 4.75, 19.6 |
| 3 | 4.75, 19.6 | {2, 4, 10, 12, 3, 11} | {20, 30, 25} | 7, 25 |

A further assignment using means 7 and 25 leaves the clusters and means unchanged. The script stops after the three requested iterations.
